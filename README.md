# THE LAST ALIBI｜最後的不在場證明

CASE 001《凌晨 00:17》第一版可遊玩網頁原型。

## 開始遊玩
1. 解壓縮 ZIP。
2. 使用 Chrome / Edge 開啟 `index.html`。
3. 開始調查，點擊書房場景中的六個標記蒐集證據。
4. 到嫌疑人審問室輸入問題、出示證據。
5. 重組時間線，再到最終推理提交答案。

## 目前版本內容
- 四名嫌疑人與各自的證詞回應
- 六項可蒐集證據及證據資料庫
- 嫌疑人自由輸入問答（目前使用預設角色回應，非真正生成式 AI）
- 證據出示與角色特殊反應
- 事件時間線重組與正確性檢查
- 最終推理、分數與三種評價結局
- localStorage 本機保存遊戲進度

## 後續 AI 串接
目前是可離線遊玩的原型。若要使用真正 AI 自由對話，需再建立 Python/FastAPI 後端並串接 AI API。API 金鑰必須放在後端環境變數，不能直接寫入前端 JavaScript。
